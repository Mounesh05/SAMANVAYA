# Requirement review lifecycle increment
Adds independent reject, request changes and revoke actions to both immutable contract and requirement-source documents. The same authorization, fingerprint, organization and compare-and-set restrictions apply. Changed proposals require a new version. Revocation conservatively marks project PR reports historical/review-required and makes existing algorithm recommendations obsolete; new job keys distinguish revoked authority. Revoked source requirements block applicable unresolved scope until replaced; old approval audit remains. Standalone PR benchmark passes approved contract and source identity into requirement preparation.

This increment does not guarantee an atomic transaction across revocation and all derived documents; concurrent dispatch, durable invalidation and recovery require testing and further hardening. Manual proposal forms, empirical analysis, full symbolic coverage and durable continuation are not completed by this commit. Tests added, not executed.
